# CBSE paper-quality audit — 9 October 2026

## Scope and confidence

Reviewed the current generator, source retrieval, guidance matching, planner, question schema, answer controls, reader, assessment and diagram pipeline. Inspected 20 locally stored paper records: six mock records excluded from content comparison, 14 non-mock records representing 12 unique question sets after exact content deduplication. Those historical non-mock records date from 29 September–2 October 2026, before the latest hardening/diagram releases. They demonstrate observed failures, not a fresh benchmark of the latest model output. No hosted database, personal student answers, new model generations or board-result data were used. No empirical board-score prediction or superiority claim is supported.

Official reference scope: 2026–27 sample papers for X Mathematics Standard, X Science, X English Language and Literature, XII Physics and XII Chemistry; X Mathematics marking scheme; linked Science/Chemistry marking schemes and Chemistry curriculum. This is a CBSE-referenced engineering/content audit, not CBSE approval or an examiner certification. Class 1/3/9/11 local papers are school/practice outputs, not Class X/XII board comparisons. Historical Chemistry and Mathematics issues remain plausible in current code because corresponding enforcement is absent; that is an inference, not a newly reproduced model failure.

## Confirmed gaps, in recommended implementation order

| Order | Gap and evidence | Required change / acceptance criterion |
| --- | --- | --- |
| 1 | **Subject/year profiles:** `_blueprint(paper_size)` ignores grade, subject, year and subject code. All grades receive 40/90 or 80/180, including primary learners. | Versioned profiles keyed by board/session/grade/subject code/variant. Distinguish chapter practice, school assessment and supported board mock. Display actual profile totals/time everywhere; unsupported subjects never imply board-format fidelity. Start X Maths Standard/Basic, X Science, XII Physics/Chemistry; separately review each profile. |
| 2 | **Invalid structure passes:** `_validate_generated_paper` checks total marks, duration, IDs, nonempty text/outlines, finite marks and diagrams; it does not enforce section counts, marks per slot, question types or chapter membership. Historical Accountancy half-paper includes one 10-mark question; historical class-1 paper has ten 4-mark questions. | Preallocate typed question slots, then validate each against the chosen profile. Reject unauthorized marks, missing sections, unknown chapters, missing required parts and wrong type counts. Repair affected slots, then revalidate the whole paper. |
| 3 | **Source identification is broken:** current NCERT catalogue has names such as `Chapter 2: Chemistry-I` and `Chapter 1: After studying this Unit, you will be … able to`, rather than canonical chapter titles. | Stable book/chapter IDs, canonical human-reviewed names, edition/session metadata, source provenance and syllabus eligibility. Keep old IDs compatible through explicit mapping. Reject empty/incorrect source selection. |
| 4 | **Retrieval mostly sees chapter beginnings:** `context_for_selection` takes first 3,500 characters per chapter, maximum 14,000 overall; the inspected Chemistry chapters contain roughly 38k–75k characters. Early topics dominate, and row order determines later-chapter exclusion. Empty chapter selection is accepted and produces zero context. | Topic-aware chunking and balanced retrieval across allocated slots, preserving equations/tables and page references. Require chapters or explicitly select the full eligible syllabus. Measure coverage per source/topic; do not label unverified extraction as approved. |
| 5 | **Guidance silently misses or is questionable:** exact subject matching means catalogue `Mathematics` misses `Maths`, `Social Science` misses `Sst`, and `English` misses book-specific labels. Current class-10 Maths/English/Social Science guidance lengths are zero. `Sst` guidance begins with Science instructions. Local guidance has no verified session/version. | Canonical alias mapping with subject/grade checks; replace reviewed stale/mislabeled guidance with source-linked profiles. Surface absent guidance operationally. No broad fuzzy matching that can attach another subject's instructions. |
| 6 | **MCQ contract is incomplete:** type is a free string, options may be absent, no stable option IDs/correct-option field. A historical XII Chemistry question labelled MCQ has neither structured nor embedded options. Its outline calls all listed concentration expressions correct, then chooses mole fraction as the incorrect answer: self-contradictory. | For single-choice questions require four distinct options where the profile calls for four, exactly one private correct option ID, and an explanation checked against each distractor. Support profile-specific two-option subparts separately. Keep keys server-side during attempts. Deterministic MCQ scoring, optional explanatory model feedback. |
| 7 | **Parts and choices are only prose:** historical English papers embed ANY TWO/ANY ONE/OR in one flat response; Chemistry case questions contain four lettered prompts without per-part marks. `parseQuestionOptions` treats two or more lettered items as options irrespective of declared question type; `QuestionInput` then treats any parsed options as MCQ, so these case subparts can become a single-choice control. | Typed stimulus + subparts with IDs/marks/response kinds; typed choice groups and `choose_count`. Attempt UI records selected alternatives and separate responses. Enforce attempted marks, navigator counts, submission and grading rules. Avoid treating subparts as MCQ options through regex parsing. |
| 8 | **Answer outline is not a marking scheme:** only a string; assessment produces a whole-question score, not audited point allocation. | Private marking points with marks, accepted alternatives, method/accuracy/unit rules where appropriate, per-part maxima and educator overrides. Sum rubric points to attempted marks. X Maths official scheme distinguishes no partial MCQ marks and fractional step marks. |
| 9 | **Scientific correctness unverified:** finite bounds/JSON/diagram validation do not detect wrong keys, unsolvable numericals or contradictions. The historical Chemistry concentration question is a concrete example. | Independent answer-solving/review pass, supported numerical/unit checks and teacher approval. Validator agreement is not proof; unresolved questions are quarantined/replaced. Record verification evidence and reviewer edits without leaking answers. |
| 10 | **Difficulty and competence are unmeasured:** no difficulty/learning-outcome/cognitive-demand fields. Quick check/Exam practice/Weak spots are strings, not enforced generation modes; weak spots does not use attempt evidence. No separate easy/medium/hard selector exists in current planner. | Separate purpose, difficulty target and question kind. Allocate cognitive demand according to the chosen official profile; do not invent a universal CBSE easy/medium/hard ratio. Use learner evidence only with a transparent choice and appropriate privacy controls. Initial difficulty tags are author estimates; calibrate with student performance. |
| 11 | **Case-based label can disguise recall:** historical Chemistry case items ask generic property/rate-law definitions rather than consistently using supplied evidence. | Require shared stimulus and subquestions that actually need its data/context; review inference/application/evidence tasks, not word count. Include experimental/data interpretation and error analysis according to subject profile. |
| 12 | **Visual coverage remains narrow:** current diagrams support simple circuits, uniform fields and flows. Official references include geometry, experimental setups, bridge circuits, tables and molecular/organic content. | Add reviewed table data and graph/geometry/experimental templates before broad visual claims. Detect missing referenced figures/tables. Provide equivalent accessible alternatives for selected profile tasks; captions alone do not guarantee equivalence. Learner drawing/working upload is a separate contract. |
| 13 | **Subject-specific response controls:** marks <=2 selects a single-line input even for reasoning/calculations; matching, multi-blank tasks and numerical working are not typed. | Drive input by explicit response kind, not marks/free-text heuristics; preserve multiline working, units, subparts and language word-limit guidance. Review reader/print options too, since structured options currently are not separately printed by `PaperBody`. |
| 14 | **Duplicate/coverage quality:** cache-recovered records repeat content by design; no semantic near-duplicate or repeated-learning-objective checks across newly generated papers. | Distinguish recovery from new variants; test repeated stems/skills, unit allocations, balanced alternatives and unnecessary duplication. Do not count duplicate recovery papers as independent benchmark outputs. |
| 15 | **No educational benchmark/release gate:** existing tests mostly establish contracts, not curricular correctness or examination realism. | Fixed matrix of real-model papers and blind educator review, with tracked generator/model/profile/source versions. Publish measured failure rates internally; no similarity percentage or board-score prediction until evidence supports it. |

## Review by question family

- **MCQ:** current selectable UI is useful; stable option identity, single-answer validation, distractor review and deterministic scoring are missing. Some historical options are embedded in text, so absence of a structured options array alone is not proof that a question has no choices.
- **Assertion–reason:** generic options can display it, but assertion, reason, their truth values and explanatory relation are not validated separately. Add a typed contract matching the selected profile.
- **Very short / short answer:** quantity of facts, command verbs, marks and expected working must match a rubric. Current single-line heuristics can obstruct valid answers.
- **Long answer / numerical / proof:** enforce complete givens/constants, solvability, units, clear expected reasoning and method-mark allocation. A long answer outline does not ensure the question earns its assigned marks.
- **Case / passage / source-based:** need shared stimulus, ordered parts and part-specific response/choice rules; prevent the current lettered-subpart parser from converting them to MCQ; preserve reading text and source accessibility. English passages should use original or appropriately licensed text.
- **Diagram / table / graph:** rendering now has a base, but the generator must only refer to supplied, supported visuals with sufficient labels/data. Review scientific equivalence and alternatives, not merely SVG existence.
- **Matching / fill blanks / primary activities:** separate age-appropriate activity profiles and controls; do not compare these to Class X/XII board structures or force long exam duration.

## Recommended delivery slices and acceptance gates

1. **Source/profile foundation:** chapter identity and guidance aliases; explicit practice vs board-mock modes; academic session, subject code, reviewed profiles and slot validator. Golden structural fixtures must reject the observed 14-question/80-mark Chemistry-style mismatch in board mode. Preserve generic practice as clearly labelled practice.
2. **Question/answer contract v2:** stable options and private keys, structured subparts and choices, private marking points. Migrate readers/attempts/Live Rooms/scoring together with legacy compatibility. Never pass a new private key/rubric field wholesale to student props; existing Live Room sanitization only strips `answer_outline`.
3. **Content quality:** balanced retrieval, independent solving/review, missing-resource checks, numerical checks and educator approval. Retain timeout/job/idempotency work from the production audit; more review passes increase latency and cost.
4. **Benchmark:** suggested initial 30-paper matrix: five starting subject profiles × three planner intents × two independently generated variants. These are proposed evaluation dimensions, not 30 board mocks—practice intents need their own targets. Add chapter subsets/full eligible syllabus, learner levels, provider paths and visual cases as coverage permits. Log schema/blueprint/coverage failures, missing resources, unresolved/ambiguous answers, verified key errors, rubric totals and reviewer judgments. Propose zero known invalid keys/missing resources in released reviewed sets; treat other thresholds as team decisions, not CBSE standards.
5. **Learning features after quality gates:** mistake notebook, targeted retry sets, per-part explanations, teacher reports, reviewable progress history and optional accommodations. Avoid adding badges or broad adaptive claims before the paper/marking contracts are reliable.

## What this audit does not establish

No current live-generation batch, experimental difficulty calibration, exhaustive subject audit, student-outcome trial, official examiner review or real-model latency/load validation was performed. Historical sample content is useful failure evidence, but newer releases may improve presentation. This audit makes no prediction that the platform will reproduce board results, and no claim that it is better than official papers. Generator behavior was not changed in this audit.
